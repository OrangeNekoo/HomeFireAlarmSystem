在ZigBee平台下，通过终端节点采集MQ-2烟雾气敏传感器和DHT11温湿度传感器采集信息，传递到协调器节点，协调器节点能判别火灾情况并在OLED上显示当前温湿度及有害气体；终端节点在OLED屏幕上显示当前日期、当前环境温湿度和有害气体；

若终端节点采集的温湿度超过阈值或者有害气体时，可实现终端与协调器节点同时声光报警，声音报警为启动有源蜂鸣器，光源报警采用LED灯闪烁的方式

2. 根据需求选择合适的传感器（如烟雾传感器、温度传感器等）并将其与 CC2530 芯片进行连接，设计硬件电路原理图，完成电路板的制作和焊接，搭建起系统硬件平台。
3. 使用 C 语言等编程语言在 IAR 嵌入式开发环境中编写程序代码。实现传感器数据的采集、处理、存储以及无线传输等功能，编写数据接收和报警逻辑控制程序。
4. 运用调试工具对硬件电路和软件程序进行调试，检查各个节点之间的通信是否正常，传感器数据采集是否准确，报警功能是否能正常触发等，对发现的问题及时进行修改和优化。
- 设计原理

1. 传感器感知 ：利用烟雾传感器和温度传感器分别感知环境中的烟雾浓度及温度变化，将这些火灾相关物理量转换为电信号。
2. 信号采集与处理 ：CC2530 主控芯片通过 AD 转换接口采集传感器传来的模拟信号，转换为数字信号后，运用滤波算法去除噪声干扰，并依据设定的判断逻辑（如与预设阈值比较等）对数据进行处理，判断是否处于火灾危险状态。
3. 控制报警模块 ：一旦判定为火灾危险，CC2530 输出电信号触发蜂鸣器发出声响报警，同时点亮指示灯，以声光结合的方式提醒人们发生火灾。
4. 无线通信功能 ：CC2530 利用其内置的无线通信功能，依据 ZigBee 等通信协议，将火灾报警信息发送给协调器节点或其他相关接收节点，实现信息的无线传输。
5. 系统整体联动 ：各部分协同工作，传感器实时监测环境情况，CC2530 进行数据处理与判断并控制报警，同时通过无线通信实现信息共享，共同完成家庭火灾的及时报警与预警功能。
