## 4. 实验相关寄存器

仔细核对引脚后将传感器插到 J8 上,光敏传感器、热敏传感器、震动传感器、酒精传感器、一氧化碳传感器等共用 P0.5 引脚，不过配置不同，当使用继电器 P0.5 作为输出引脚，使用光传感器时配置成输入引脚。

void InitLed(void)
{
    P1DIR |= 0x01;    //P1.0 定义为输出口
}

/**********************************************************************
* 名 称: DelayMS()
* 功 能: 以毫秒为单位延时 16M 时约为 535,系统时钟不修改默认为 16M
* 入口参数: msec 延时参数，值越大，延时越久
* 出口参数: 无
**********************************************************************/
void DelayMS(uint msec)
{
    uint i,j;

    for (i=0; i<msec; i++)
    for (j=0; j<535; j++);
}

void main(void)
{
    P0DIR &= ~0x20;    //P0.5 定义为输入口
    InitLed();    //设置 LED 灯相应的 IO 口
    while(1)    //死循环
    {
    if(DATA_PIN == 1)    //当光敏电阻处于黑暗中时 P0.5 高电平,LED1 熄灭
    {
    LED1 = 1;
    DelayMS(1000);
    }
}
